# Animu Finder Compose

Compose Multiplatform test project

## Getting started

### Launch desktop
```shell
./gradlew :desktopApp:run
```

### Launch web (wasm)
```shell
./gradlew :webApp:wasmJsBrowserDevelopmentRun
```


### Launch android
In Intellij IDEA (with android plugin) or Android Studio, select the android `MainActivity` run configuration and run it
